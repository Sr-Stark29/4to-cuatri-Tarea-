# Nova Store 

## Estructura
- index.html
- login.html
- tienda.html
- css/estilos.css
- img/producto.jpg

## Funcionamiento
1. `index.html` redirige a `login.html`.
2. En el formulario de login se solicita usuario/correo y contraseña.
3. Al presionar "Iniciar sesión", se abre `tienda.html`.
4. En la tienda se muestra el producto, imagen, descripción, precio, características y botón "Agregar al carrito".
